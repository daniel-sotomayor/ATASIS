1. Introducción

El Generador de Actas INTi es una aplicación diseñada para facilitar la generación de actas oficiales del Instituto Nacional de Tierras (INTi). Esta herramienta permite procesar archivos Excel con puntos de cuenta y generar automáticamente documentos Word formateados según los estándares del INTi.

Importante: Este software es propiedad de DTSR C.A. y fue desarrollado por Danielo Sotomayor como un apoyo prestado al INTi. No debe ser vendido, plagiado o distribuido comercialmente sin autorización expresa.

2. Requisitos del Sistema

  • Sistema operativo: Windows 10 o superior
  • Memoria RAM: Mínimo 4 GB (recomendado 8 GB)
  • Espacio en disco: 500 MB para instalación
  • Microsoft Excel (para abrir archivos de origen)
  • Microsoft Word (para abrir las actas generadas)

3. Instalación

  1. Ejecute el archivo Instalador_GeneradorActasINTi_v1.0.0.exe
  2. Lea y acepte el acuerdo de licencia
  3. Seleccione la carpeta de instalación (por defecto: C:\Program Files\Generador de Actas INTi\)
  4. Elija si desea crear accesos directos en el Escritorio y Menú Inicio
  5. Complete el asistente de instalación
  6. Ejecute la aplicación desde el acceso directo creado
Nota: La aplicación creará automáticamente las carpetas necesarias en Documentos\Actas de ATASIS y AppData\Local\Generador de Actas INTi para almacenar las actas generadas y la base de datos.

4. Configuración

La aplicación viene preconfigurada con los datos del directorio del INTi. No es necesario configurarla a menos que desee cambiar:

  • Nombre del Presidente
  • Nombres de los Directores Principales
  • Nombres de los Directores Suplentes
  • Nombre de la Secretaria
  • Horas de inicio y fin de las sesiones
  • Número de reunión

Para cambiar la configuración:

  1. Abra la aplicación
  2. Vaya al menú Archivo → Configuración
  3. Modifique los campos deseados
  4. Haga clic en Guardar
  5. Los cambios se aplicarán inmediatamente

5. Uso de la Aplicación

La aplicación tiene tres pestañas principales:

  • Dashboard: Muestra estadísticas y actas recientes
  • Generar Actas: Para cargar Excel y generar documentos
  • Historial: Registro de todas las actas generadas con búsqueda

6. Dashboard

El Dashboard muestra:

  • Total de Actas: Cantidad de actas generadas
  • Total Aprobados: Suma de puntos aprobados en todas las actas
  • Total Negados: Suma de puntos negados en todas las actas
  • Total Sesiones: Número de sesiones procesadas

También muestra tablas con:

  • Estadísticas por Estado
  • Últimas 10 actas generadas

7. Generar Actas

Pasos para generar actas:

  1. Vaya a la pestaña Generar Actas
  2. Haga clic en Cargar Excel y seleccione su archivo
  3. El archivo debe tener las columnas: Id punto de cuenta, Tipo de solicitud, Estado, Decisión, Sesión, Fecha
  4. La aplicación mostrará las sesiones detectadas en el Excel
  5. Seleccione las sesiones que desea generar (casillas de verificación)
  6. Haga clic en Generar Actas Seleccionadas
  7. La barra de progreso mostrará el avance
  8. Las actas se guardarán en Documentos\Actas de ATASIS
Advertencia: Las sesiones que ya tienen acta generada aparecerán en verde en la lista. Si regenera una sesión, se sobrescribirá el acta anterior.

8. Historial

La pestaña Historial permite:

  • Ver todas las actas generadas
  • Buscar por número de sesión, fecha u observaciones
  • Abrir el documento Word generado
  • Ver detalles de cada acta
  • Exportar el historial a Excel

Para buscar actas:

  1. Vaya a la pestaña Historial
  2. Escriba el término de búsqueda en el campo de texto
  3. La tabla se filtrará automáticamente

9. Solución de Problemas

El Excel no carga correctamente

  • Verifique que el archivo tenga las columnas requeridas
  • Asegúrese de que la hoja de datos se llame "Base"
  • Verifique que no haya filas vacías al inicio

Error al generar actas

  • Verifique que tenga permisos de escritura en las carpetas de la aplicación
  • Asegúrese de que Documentos\Actas de ATASIS exista y sea accesible
  • Cierre cualquier documento Word abierto que pueda estar en uso

La aplicación no inicia

  • Verifique que tenga Microsoft .NET Framework instalado
  • Ejecute el instalador nuevamente para reparar la instalación
  • Consulte con el administrador del sistema si tiene permisos suficientes

Configuración no se guarda

  • Verifique permisos de escritura en la carpeta de instalación
  • Ejecute la aplicación como administrador
